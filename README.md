# Calisthenix

Calisthenics coach & tracker — Uzbek / English / Russian.

- Coach: create exercises (121 illustrated bodyweight exercises with a red muscle map), build weekly programs with sets, reps/seconds and rest.
- Athlete: today's workout, guided player with animation, set checklist and rest timer, stats (heatmap, personal bests, body weight).

## Run it
It is a static site: just open `index.html`, or publish it with GitHub Pages.

On this standalone site, data is saved in the browser (localStorage) on that device.
Use **Murabbiy → Zaxira nusxa** (Coach → Backup) to download a backup file or restore it on another device.
